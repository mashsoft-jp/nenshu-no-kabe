# 配偶者・その他の控除

変更・一次資料確認日：2026-09-10。扶養条件のPR #5へ追加。ユーザーの依頼は「配偶者控除も追加」「他にも控除する条件があればそれも追加」。完成後のpush・PR・Bugbotの指摘なし確認後のマージも承認済み。既存Pagesはmainへのマージで配信される。

## 対応範囲と入力

国内居住・本人は給与所得のみの既存モデルを維持する。「配偶者・その他の控除」は給与条件内の折りたたみ。資格要件を満たすことを選択し、計算できる所得上限・所得区分を自動判定する。本人の給与所得控除・基礎控除・税率は変更しない。

- 配偶者控除・配偶者特別控除：配偶者の合計所得、70歳以上、資格の有無を入力。所得は給与の額面収入ではない。民法上の配偶者・同一生計・非専従者・重複適用なしを前提とし、配偶者と互いに控除を受ける条件は対象外。
- 障害者控除：本人、同一生計配偶者、扶養親族を区別。扶養親族は一般・特別（同居以外）・同居特別を重複しない人数で入力し、既存扶養人数の内数として検査。16歳未満も含む。
- ひとり親（父／母）・寡婦（離婚／死別等）・勤労学生：資格要件は画面に表示。本人所得上限を自動判定。ひとり親・離婚後の寡婦は扶養人数の入力も必要。本人の死別・再婚など年途中の特則による配偶者控除との併用は対象外。
- 特定親族特別控除：19〜22歳の資格を満たす親族の合計所得を1人ずつ入力。扶養人数との重複を禁止する案内を表示。扶養親族と合計10人まで（実装上限）。所得が扶養区分以下・特定親族上限超ならエラー。
- 所得金額調整控除：23歳未満の扶養親族に加え、本人・家族の特別障害者を判定。他の人が扶養控除を受ける23歳未満の扶養親族の有無も入力できる。特定親族特別控除の対象者は扶養親族ではないため、この加算条件には含めない。
- 小規模企業共済等掛金（iDeCo等）、追加社会保険料、生命保険料、地震保険料、医療費、雑損、寄附金：申告書等で算定した控除額の入力。所得税と住民税で額が異なる項目は別々に保持する。支払保険料・医療費そのものからの算定機能ではない。
- 住宅ローン・寄附金等の税額控除：所得税、住民税区市町村分、都道府県分の控除可能額を別入力。制度の適用要件・制度上限を確認した金額に対する税額計算。借入残高からの算定、所得税から住民税への未使用額の自動移行、ふるさと納税の上限試算は行わない。

税額控除の上限などは収入や仮想制度で変わり得るため、手入力額を固定した比較であることを画面に明記。外国税額控除（復興特別所得税への適用を含む）、給与以外の所得に係る控除、繰越・還付、年金所得との所得金額調整控除は対象外。手入力欄でこれらを再現できるとは案内しない。

追加控除は税金の計算だけに使う。iDeCo等の支出を給与天引きと推定したり、生活費として手取りから再度差し引いたりしない。追加社会保険料は既存の年間社会保険料へ含めていない額だけを入力。医療費控除とセルフメディケーションは選択適用で、後者は算定済み8.8万円以下の額を入力する。寄附金の所得控除と税額控除は同じ寄附について重複適用しない。ワンストップ特例は住民税だけに入力し、基本分・特例分と申告特例分を専用欄で分ける。

## 対象期間

| 表示 | 所得・条件の年 | 適用 |
| --- | --- | --- |
| 通常月の源泉所得税 | 2026年の見積り・9月の制度 | 扶養等申告書の人数。扶養所得要件58万円・配偶者95万円・本人900万円・学生85万円の基準 |
| 年間所得税 | 2026年分 | 2026年12月1日施行の所得要件62万円・学生89万円を使用 |
| 年間住民税概算 | 2027年度・2026年所得 | 今年の条件・控除を反映 |
| 通常月の住民税概算 | 2026年度・2025年所得 | 前年の条件。所得要件58万円・学生85万円 |

前年の追加条件は「今年と同じと仮定」または「個別指定」。前年の扶養人数とは別設定なので、矛盾する障害者人数・ひとり親等の扶養なしを検査する。配偶者所得を同額と仮定しても2025年と2026年の所得上限は別に判定する。年末の年齢・家族構成・所得が変わる場合は個別指定する。

通常月の自動人数には源泉控除対象配偶者、特定親族のうち所得100万円以下、本人や家族の障害者・同居特別障害者、ひとり親等を加算する。本人所得見積りは12月改正前の給与所得控除を使用。年間条件と勤務先への申告が異なる場合は既存の通常月人数を手入力して優先する。源泉人数上限は障害者等の加算を扱うため40人に拡張（扶養親族の実人数は合計10人のまま）。保険・医療費等の年額控除は通常月の源泉所得税には流用しない。

通知済み住民税年額・月額の直接入力はすべての概算に優先し、控除変更でも上書きしない。

## 金額・丸め

実装は `deduction-engine.js`。すべて円の整数で保持。配偶者の本人所得区分は900万円以下／950万円以下／1,000万円以下。配偶者の所得区分は国税庁・自治体表を別々に使用する。配偶者特別控除と特定親族特別控除の調整控除用差額は0であり、所得税額用控除と住民税額用控除の単純差を使わない。

障害者控除は所得税27／40／75万円、住民税26／30／53万円。ひとり親は所得税35万円・住民税30万円、調整控除用差額は父1万円・母5万円。寡婦27／26万円、勤労学生27／26万円。本人障害者・ひとり親・寡婦で所得135万円以下の住民税非課税も反映。

同一生計配偶者は住民税非課税人数に含める。配偶者控除に本人1,000万円上限があっても、同一生計配偶者に係る障害者控除の判定とは分ける。所得金額調整控除は給与850万円超の10%、給与上限1,000万円・控除上限15万円・1円未満切上げ。基礎控除や配偶者控除の本人所得判定より先に給与所得から引く。

手入力の生命保険料控除上限は所得税12万円・住民税7万円、地震保険料控除5万円・2.5万円、医療費控除各200万円。新旧生命保険の合算、2026年分以降の23歳未満扶養による新生命保険料上限特例は、利用者が算定した控除額に含める。寄附金入力額は2,000円差引後とし、各年収シナリオで `max(0, floor(所得×40%)−2000)` でも上限を設ける。

年間所得税は所得控除後に1,000円未満切捨て→累進税額→税額控除（0円下限）→復興特別所得税2.1%の1円未満切捨て→合計100円未満切捨て。税額控除前と適用額を内訳に表示。

住民税は調整控除→区・都それぞれの手入力税額控除（各0円下限）→非課税基準近傍の所得割調整→ワンストップ申告特例分→区・都別100円未満切捨て。税額控除で均等割・森林環境税は減らさない。所得割調整は税額控除後の金額を基準にする。所得割調整は税額控除後の実際の区・都の所得割に比例配分する（固定3:2ではない）。内部の率計算は百分の一円単位、按分はBigIntの有理数として最終100円丸めまで保持する。追加住民税条件がない旧扶養0人の計算は既存エンジンの結果を維持する。

## 保存・互換・表示

JSONはversion 5。`taxConditions`、`previousTaxConditions`、`previousTaxMode`を追加する。version 1〜4では追加控除なしで移行し通知する。version 4の扶養を保持し、version 1〜3の扶養0人移行も維持。旧バージョンに紛れ込んだ新項目は無条件に初期値で置き換える。version 5の欠落・型違い・負数・小数・上限超過・不整合は拒否し、入力エラー時は出力操作を止める。

所得税・住民税の「詳細」に追加控除の種類・額・税額控除の適用額を表示。年収別グラフで配偶者等の所得上限に近い点を追加し、境界を補間で飛ばしにくくする。現行・仮想の両方に同じ条件を適用。CSVは控除条件・金額・通常月人数を含め、各年収シナリオの源泉人数を算定し、引用符をエスケープする。コピー・JSONにも追加条件を含める。外部送信・自動保存は追加しない。

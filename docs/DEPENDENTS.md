# 扶養条件の入力

確認日：2026-09-09。基点：main `39dc2d1`。ユーザーの扶養条件入力の依頼に対応するローカル変更。マージ・push・公開はこの変更の承認に含めない。

## 入力と対象

給与条件に「扶養条件」の折りたたみを追加。初期値は全区分0人。配偶者以外の、本人が税法上扶養する国内居住親族を人数で指定する。所得や年齢を個人ごとに保存せず、要件を満たす人数を入力する。生計を一にすること、事業専従者でないこと、他の所得者と扶養控除を重複させないことが前提。人数上限10人は入力・計算の実装上の制限であり法令上限ではない。

| 区分 | 所得税の年間扶養控除（円/人） | 住民税の扶養控除（円/人） | 人的控除差（円/人） |
| --- | ---: | ---: | ---: |
| 16歳未満 | 0 | 0 | 0 |
| 16〜18歳 | 380,000 | 330,000 | 50,000 |
| 19〜22歳（特定） | 630,000 | 450,000 | 180,000 |
| 23〜69歳 | 380,000 | 330,000 | 50,000 |
| 70歳以上（同居老親等以外） | 480,000 | 380,000 | 100,000 |
| 70歳以上（同居老親等） | 580,000 | 450,000 | 130,000 |

同居老親等は本人又は配偶者の直系尊属で同居を常とする人。他区分との重複入力はしない。区分は当該所得年の12月31日時点。2026年分所得税・2027年度住民税には2026年の条件、2026年度住民税には2025年の条件を使う。

2026年の年間合計所得要件は62万円以下。原則2026年12月1日施行・2026年分所得税から適用される制度を使う。2025年分は58万円以下。給与収入（額面）と所得を同一視しない。月々の源泉徴収には2026年の電算機計算特例を継続使用し、年末の控除改正を前倒し適用しない。

通常月は、入力した16歳以上の人数を源泉徴収人数と同じと仮定するモードが初期値。勤務先への申告人数が異なる場合は0〜10人で個別指定する。この入力は年間の扶養控除に影響しない。例えば一般扶養の所得が58万円超62万円以下の場合、年額の対象でも通常月の対象とは限らないため個別指定する。配偶者（特別）控除、特定親族特別控除、障害者・ひとり親等の控除は今回の年間計算の対象外。

前年は、上と同じ人数・区分と仮定するモードが初期値。前年から16歳・19歳・23歳等の区分が変わった場合や所得要件が異なる場合は、前年の区分別人数を個別指定する。現在の年齢から前年の年齢を推測しない。

## 計算

- 通常月：`monthly-engine.js` の電算機計算特例に指定人数を渡す。1人当たり31,667円を課税給与所得から控除する。税率・給与所得控除・基礎控除・10円単位の四捨五入は変更しない。
- 年間所得税：給与所得から社会保険料・基礎控除・扶養控除を引き、0円を下限に1,000円未満切捨て。所得税・復興特別所得税を計算し合計100円未満切捨て。仮想制度側にも同じ扶養控除を使う。基礎控除の判定に使う合計所得から扶養控除を先引きしない。
- 23歳未満の入力親族がいる場合、課税対象給与収入850万円超の所得金額調整控除も計算する。`ceil((min(給与収入, 1000万円) − 850万円) / 10)` 円、下限0円・上限15万円。人数を掛けない。給与所得から差し引いてから基礎控除等を判定する。所得税・住民税両方へ反映する。扶養控除を他の所得者が適用している子に係る本人の所得金額調整控除、特別障害者・年金所得による調整控除は今回の入力の対象外。
- 東京23区の住民税概算：扶養控除、人的控除差に基づく調整控除、扶養人数を含む非課税判定を反映。16歳未満は扶養控除0円だが非課税人数に含める。扶養ありの均等割等の所得限度は `350,000 × (1＋人数)＋310,000` 円、所得割の限度は同 `＋420,000` 円。
- 調整控除の基礎となる人的控除差は基礎控除分50,000円＋扶養区分の差額。住民税課税所得200万円以下はその課税所得と差額の小さい方。200万円超は差額から200万円超過分を引き50,000円を下限とする。合計所得2,500万円超は対象外。仮想の所得税基礎控除から差額を作らない。
- 扶養ありの所得割非課税限度直上では、所得割を差し引いた所得が非課税限度を下回らないよう調整措置を反映する。区・都へ3:2で配分後、それぞれ100円未満を切り捨てる。内部では円の100分の1の整数分子を用いる。
- 通知書の直接指定年額・月額は扶養条件で変更しない。給与天引きがない場合の直接月額0円を維持する。普通徴収の年額入力・徴収方法の拡張は本変更に含まない。

`unified-engine.js`に扶養区分・住民税・給与所得調整の関数を追加。`policy-engine.js`の所得税計算に扶養控除の任意引数を追加（未指定0円）。既存の扶養なし計算・保険料率・税率そのものは変更しない。

## 保存・出力・画面

JSONは `nenshu-no-kabe` version 4。追加フィールドは `dependents`、`previousDependents`（under16 / young / specific / adult / elderly / cohabiting）、`withholdingDependentMode`、`withholdingDependents`、`previousDependentMode`。人数欠落・不正値・合計上限超過・不正モードを拒否する。

version 1〜3は全扶養0人として移行し、その旨を通知する。旧ファイルに新フィールドが混入していても採用せず、従来の計算結果を保持する。version 1の月給換算、version 2の年額・月額住民税の独立性を維持する。

CSV・コピーに今年/前年の扶養区分と源泉徴収人数、控除額を含める。所得税と住民税の既存「詳細」に扶養控除・対象年・人数を表示し、開いた状態で再計算する。所得金額調整控除は所得税の詳細内に表示する。ユーザーの実際の明細・給与設定はソースやテストに保存しない。

## 検証・受入条件

独立した合成例：月給40万円・賞与なし・30歳・東京・雇用保険0.5%・扶養16〜18歳1人・年額社会保険料60万円を直接指定。通常月は自動保険料60,178円、社保控除後339,822円、給与所得控除104,632円、基礎控除48,334円、扶養31,667円、課税給与所得155,189円×5.105%→7,920円。年間は給与所得340万円−60万円−104万円−38万円＝138万円、所得税69,000円×1.021→70,400円。住民税は課税204万円、調整控除の基礎60,000円、区120,600円＋都80,400円＋5,000円＝206,000円。

- `test-dependents.cjs`：区分別の固定期待値、上限・不正入力、月額/年額/前年の独立性、通知書優先、非課税境界、調整控除・調整措置、給与所得調整の端数・上限、JSON移行、仮想制度・グラフの条件維持。

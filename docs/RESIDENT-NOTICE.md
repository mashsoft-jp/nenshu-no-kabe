# 通知書の住民税年額と月額

変更日・一次資料確認日：2026-09-09。基点：main `082b9d0c57b30d497423c31d10edc20e9028e207`。

## 決定と対応

ユーザーは、通知書年額からその対象年度の月額を算出し、6月分と7月〜翌5月分を分けて表示する提案を「ではそのように」と承認した。以下はその実装であり、通常月の源泉徴収・社会保険料を月別に作り直す変更ではない。

- 詳細条件の住民税を年額入力→徴収方法→月額設定の順に配置。
- 年額入力の選択・編集時に `monthlyResidentMode: annual` へ切り替える。月額の直接入力（manual）は優先し、上書きしない。
- 給与特別徴収の年額（森林環境税込み）から6月、7月〜翌5月の配分を算出。内訳の「詳細」にも式と適用条件を表示し、展開したまま再計算。
- 通常月の手取りには7月〜翌5月分を使用。住民税差だけを反映した6月の手取りを併記し、他の控除は通常月と同じ固定条件と明記。
- 年間の手取り・月平均にも同じ入力年額を使用。通知済みの税額を2027年度の予測と表示しない。
- 年額を自動概算に戻すと、年額連動中の月額は2026年度の概算へ戻す。月額の直接指定中は保持する。
- 手取りより下の所得税オプション、階段状グラフ、賞与・その他控除・従来の独立月額設定を維持。

## 計算式と範囲

通常の12回徴収：

```text
7月〜翌5月の各月額 = floor(年額 / 1200) * 100
6月分 = 年額 - 各月額 * 11
```

年額240,500円なら6月20,500円、7月〜翌5月各20,000円。合計は240,500円で、毎月の単純な四捨五入はしない。

入力は給与特別徴収の年額だけを対象とする。普通徴収・年金天引き分や通知書の未徴収残額を合算・再配分しない。年度途中の転職、徴収開始、税額変更、複数の徴収方法の併用は年額だけで復元しない。通知書と配分が違う場合は通知書の月額を直接指定する。

少額等による6月の全額徴収は `residentCollectionMode: june` を通知書に合わせて選択する。既定値の `split` は通常の12回徴収という計算条件であり、年額だけから一括徴収の適否を判定した結果ではない。全国共通の少額閾値は今回追加しない。協会けんぽ支部は住民税の自治体ではないため、支部から閾値を推測しない。

年額0円は全月0円。従来の年額入力範囲（0〜50,000,000円の整数）を維持し、入力した端数も合計に保持する。通知書の月額を直接指定している場合、6月の手取りは推測しない。

## 出典（今回確認した一次資料）

- 愛知県美浜町「個人住民税・森林環境税の納付方法」：給与特別徴収は6月から翌5月の12回、100円未満の端数は初回に加算。公式例は年額60,200円→6月5,200円、残り各5,000円。
  https://www.town.aichi-mihama.lg.jp/soshiki/zeimu/juminzei/1/2/5/25.html
- 岩倉市「個人市県民税の給与特別徴収」：均等割額に相当する金額以下の初月全額徴収に言及。この自治体の条件を全国共通として自動適用しない。
  https://www.city.iwakura.aichi.jp/0000000271.html
- つくば市「特別徴収開始月の運用変更について」：年度途中の切替には開始月の指定があるため、通常12回の配分だけで再現できない。
  https://www.city.tsukuba.lg.jp/kurashi/zeikin/shiminzei/tokucho/26926.html

所得税・住民税の税率や控除の再検証は本変更の範囲外。CALC-001 / QA-001全体の完了を意味しない。

## JSON・CSV・コピー

新しい保存形式は `nenshu-no-kabe` version 3。入力へ `residentCollectionMode: split|june` を追加し、`monthlyResidentMode` に `annual` を追加。年額モードがmanualでない状態のannual連動は拒否する。

version 2の読込では徴収方法をsplitで補い、元の月額設定（estimate / previous / manual）を維持する。年額入力がある旧設定では「年額と月額を別々に保持した」ことを通知する。ユーザーが連動を選択するまで保存済みの結果を変えない。version 1の給与換算も引き続き対応する。version 3では徴収方法の欠落・不正値を拒否する。

CSVには年額の根拠、通常月住民税、月額の根拠、通知書からの6月・7月〜翌5月配分（参考値）を追記。コピーには通常月の税額と根拠、年額連動中のみ6月の税額・手取りを含める。

## 2026-09-10 月給から住民税を天引きしない選択

「通常月の住民税」に「月給から天引きしない（自分で別途支払う）」を追加。通常月の住民税は0円、年間の税額・年間手取りは従来どおり別払いの負担を含める。年額・年額計算方法を変更しても天引きなしを維持する。別払い時は年額入力の説明を切り替え、給与特別徴収の配分と6月手取りは非表示、CSVの配分欄は空欄とする。普通徴収の各期納付額は計算しない。

JSON version 6に `monthlyResidentMode: none` を追加。旧version 1〜5は既存の移行を維持し、天引き方法を勝手に変えない。旧versionでのnone指定と未知のモードは拒否する。既定は従来どおり前年同額の概算。受入条件は月額のみ0円・年額維持、年額編集後の選択維持、JSON復元、狭幅での表示。

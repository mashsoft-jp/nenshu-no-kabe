# 仕様書ドラフト

対象：年収の壁 v0.7 / 整理日：2026-09-09

この文書は現行ソースと会話の要件を整理したもの。数値上限などの試作制限は、ユーザー確定要件とは区別する。制度の数字を新しく承認する文書ではない。

## 1. 画面構成

単一ページを維持する。PCは入力と結果を左右に置き、狭幅では縦に並べる。

1. ヘッダー：年収の壁、入力値の非送信表示、結果コピー。
2. 給与条件：月給、任意賞与、算出年収、支部・年齢。詳細条件は折りたたむ。
3. 手取り額：通常月、年間（賞与込み）、年額÷12の月平均、額面年収の式。
4. 内訳：月額と年額の構成バー・同一表。項目別「詳細」。
5. 所得税の変更：初期状態は閉じたオプション。
6. 年収別グラフ、計算条件の補足、比較表・CSV、制度の前提・資料。

税制比較を前面に出して手取りを押し下げない。見出しは「給与条件」「手取り額」「内訳」「所得税の変更」等にする。

## 2. 入力と年収

### 基本入力

| 値 | 現行仕様 |
| --- | --- |
| 月給 | 額面・手当込み、円単位。毎月同額を想定 |
| 賞与 | 任意。支給月1〜12月・額面を追加/削除。最大3件は試作制限 |
| 額面年収 | `monthlyGross * 12 + bonusesのgross合計`。直接編集せず導出 |
| 支部 | 居住地ではなく協会けんぽ加入支部。47支部の実装データを使用 |
| 年齢 | 20〜64歳。資格判定や誕生日月の再現はしない |

エンジンの月給範囲は80,000〜8,333,333円、年収上限は100,000,000円。賞与を含む計算年収でも上限を確認する。最低年収等の制限は給与モデルの入力範囲であり、社会保険加入条件を判定した結果ではない。

### 詳細条件

非課税通勤手当、雇用保険区分、決定済みの標準報酬月額、前年の給与収入・社会保険料、通知済み住民税、年間社会保険料の直接指定、その他給与控除を保持する。賞与が1〜3月にある場合は、健康保険の上限判定用に前年4〜12月の標準賞与累計を指定する。前年賞与額を当年の額面年収へ加算しない。

非課税通勤手当は入力した額面に含まれる内数。その他給与控除は税法上の所得控除と区別する。

## 3. 表示する金額

| 結果 | 意味 |
| --- | --- |
| 通常月の手取り | 月給 − 通常月の社会保険料 − 源泉所得税等 − 給与天引き住民税等 − その他月額控除 |
| 年間の手取り | 月給×12＋賞与 − 年間社会保険料 − 年間所得税等 − モデル上の年間住民税等 − その他月額控除×12 |
| 年間の月平均 | 年間手取り÷12。通常月の振込額と同じとは限らない |
| 仮想制度の差額 | 同じ給与・保険条件で計算した変更後年額 − 現行制度年額 |

現行実装では通常月と年間で対象期間・所得税の計算方法・住民税年度が異なる。年額を実際の1〜12月の入出金合計と呼ばない。現行モデルの期間は `PROJECT.md` と `SOURCES.md` に記載する。

## 4. 内訳と詳細

健康保険、介護保険、厚生年金、子ども・子育て支援金、雇用保険、所得税等、住民税等、その他控除、手取り等を表示する。年額社会保険料を手入力した場合は自動計算した細目の合計と混同しない。

「詳細」は項目名と対応付け、押した項目の直下に計算式と条件を表示する。同時に複数項目を開ける。条件変更後も展開状態を保ち、内容だけを再計算する。`aria-expanded`、対象要素との対応、フォーカス表示を保つ。

健康保険の表示形式例：

```text
標準報酬月額 × 支部の保険料率 ÷ 2（支部名）
月額 × 12 ＋ 賞与分 ＝ 年額
```

式に使う値はその時の計算結果から作る。標準報酬月額、本人負担、端数処理、対象外理由を表示する。所得税は同じ項目の詳細内で月次の計算条件と年間の課税所得の導出・税率区間別内訳を示す。独立した重複「計算根拠」カードは再導入しない。

## 5. 所得税の仮想変更

現行制度は編集不可。仮想側の課税所得上限・税率を編集し、区分の分割・削除に対応する。現行の実装制限は1〜20段階、率0〜100%、最終区間は上限なし。上限の非昇順、無効な数字等を拒否する。率は下位より低い設定も仮想制度として許容し、単調増加を勝手に要件化しない。

速算表の控除額を固定して流用せず、課税所得を区間ごとに分けて算出する。基礎控除変更は現行実装にある追加機能として維持する。給与所得控除・住民税制度・社会保険加入条件まで同時に変えない。

変更後の年間手取り・差額と内訳の変更後列を表示する。通常月の源泉徴収は変更しない。折りたたみを閉じても設定を保持し、変更中を示す。「現行に戻す」で取り消す。

## 6. 賞与と社会保険

月給と賞与を分けて計算し、賞与を月給へ均して標準報酬月額を決めない。同月賞与の集計、標準賞与額の端数処理、健康保険の年度枠と厚生年金の月枠、前年枠を現行のモデルとして扱う。

賞与ごとの源泉徴収税額や支給時の振込額は算出しない。賞与を年間給与所得へ合算して年間所得税を計算する。実際の支給月ごとの料率・資格・免除等を再現する機能は未実装。

## 7. グラフ・保存

グラフは年収×手取り、年収×増減額、税率の段階を切り替える。年収を動かす場合は賞与を固定し、月給を変える。円単位への変換・丸めで目標年収と差が出る場合、実際に計算した年収と入力を整合させる。

設定JSONは月給・賞与・制度設定等を保存する。旧形式は既存の移行処理を維持し、変換時には通知する。独自JSON形式を新設する場合はマイグレーションを設ける。CSVには月給・賞与・計算に使った年収と結果を含める。不正形式・上限超過等はエラーとして扱う。

## 8. 非機能と未決事項

現在は外部送信・自動保存・アクセス解析なしのブラウザ内計算。公式資料のリンク操作のみ外部通信を伴う。サーバー・認証・DB・フレームワーク移行・クラウド保存は未決定。

Chrome相当の既存テストはあるが、Safari/Firefox/実機モバイルの網羅的な検証は未完了。一般公開、利用案内、ライセンス、制度データの更新運用は別の完了条件を設ける。

## 9. 仕様の根拠

ユーザー確定事項は会話履歴と `docs/DECISIONS.md`。実装の確認先は `unified-engine.js`、`unified-ui.js`、`unified-view.html`、既存エンジン・テスト。制度の一次資料リンクは `SOURCES.md` に引き継いでいるが、公開前に適用時期・数値・丸めと照合する。

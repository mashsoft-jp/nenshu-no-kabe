# 税率設定のグラフ

対象：2026-09-09のUI変更。基点はmainの `3c355d90bba243e4ed805be588c5191b413a7a58`。

## 決定事項

ユーザー依頼により、税率設定の隣の括弧書きを削除し、見出しを「税率設定」にする。税率の全段階をまとめ、どの金額で税率が変わるかを視覚化する。

実装は階段状の折れ線。斜めの補間によって区間内で税率が徐々に上がるようには見せない。横軸は課税所得（万円）で金額に比例、縦軸は税率（%）。最終区間は上限なし。税率が下がる設定や同率の区間も既存仕様どおり許容する。手取り・内訳の下にある折りたたみオプション内に置く。

## 実装

- `unified-view.html`：見出しとグラフ・選択表示を、数値欄の前の全幅領域に配置。
- `rate-chart.js` / `rate-chart.css`：全区分のSVG、境界ラベル、選択、レスポンシブ表示。
- `build.py`：新しいJS/CSSを単体HTMLに同梱。外部ライブラリや通信は追加しない。
- `docs/SPEC.md`：第5節に表示・操作要件を追加。

既存の `unified-ui.js` が描画する数値欄を読み取り、入力イベント・ラベル/選択のDOM更新を監視する。税率データやUndo履歴は複製せず、段階選択は既存の `.sim-pick` ボタンへ委譲する。将来、入力欄のDOM契約（行・data-field・選択表示）を変える際は、このコンポーネントとテストも同時に更新する。

全ての境界が入るよう軸を自動調整し、下段の年収比較グラフの表示上限に引きずられない。密集するラベルは重なりを避けて省略し、正確な金額・率は選択欄と既存の数値欄で確認できる。入力エラー時は古いグラフを消す。閉じている間は描画を止め、再展開時に最新設定を反映する。
